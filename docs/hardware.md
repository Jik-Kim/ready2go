# 실물 작업 공간 · 하드웨어

> 관련 요구사항: [FR-ACT-01–04](requirements.md#fr-act-01), [NFR-SAF-01](requirements.md#nfr-saf-01). 실제 작업 공간과 장비 구성 상세는 이 문서에서 다룹니다.

## 2. 실물 작업 공간 · 하드웨어 구성

### 2.1 작업 공간 배치
```
          [실물 서랍장 (작업대에 고정)]
               ▲ 인출 방향
   [M0609 + RG2 + 손목 RealSense]   [전달 트레이(handover_zone)]
                                       ▲ 사용자 위치
```
* 서랍장과 사용자 전달 트레이(`handover_zone`)는 **M0609 작업 반경(900mm) 안**에 둠. 전달 트레이의 실제 설치·좌표 기준은 `config/places.yaml`을 따름. P2 장애물은 같은 서랍 내부 빈 공간으로 옮기므로 외부 임시 트레이(`staging_tray`)를 필수 장비로 두지 않음. 잔존 설정·참조 정리는 B·C·E 인계이며 전달 트레이는 유지함. [문서]
* 사람에게 직접 건네지 않고 **전달 트레이에 내려놓음**(11장 안전).

### 2.2 실물 서랍장 구매 · 설치 기준 (담당 E, Day 0~2)
철제 고정대 + 원목 2단 서랍장(금속 레일)을 사용하며 작업대에 고정함. 교체·설치 결정은 [#1 최신 정리](https://github.com/Jik-Kim/ready2go/issues/1#issuecomment-5980612526), 실측 치수·인출 거리·좌표계는 [`config/places.yaml`](../config/places.yaml)을 참조함. [문서]

| 항목 | 기준 | 이유 |
| :--- | :--- | :--- |
| 재질·색 | **불투명·무광**, 내부는 밝은 단색 | 반투명·광택 플라스틱은 RealSense 뎁스가 투과·반사로 깨짐. 물품과 배경 대비 확보 |
| 단 수·크기 | 원목 2단, 작업 반경 안에 설치 | 사용 서랍은 `drawer_top`·`drawer_bottom`. 실측 설정은 [`config/places.yaml`](../config/places.yaml) 참조 |
| 인출 | 스토퍼 있음(완전히 빠지지 않음), 깊이의 절반 이상 인출 가능 | 아래 서랍은 윗 서랍에 가려 **인출된 부분만** 위에서 보이고 집을 수 있음 |
| 손잡이 | **돌출형 손잡이**, 없으면 막대형 손잡이를 부착 | 홈형 손잡이는 RG2로 파지 불가. 손잡이 뒤 손가락 들어갈 공간 확보 |
| 고정 | 클램프·양면테이프·볼트로 **작업대에 고정**, 필요 시 무게 추가 | 가벼운 서랍장은 당길 때 함께 끌려오거나 넘어짐. 위치가 바뀌면 교시 포즈가 무효 |
| 레일 | 금속 레일의 유격·걸림과 실제 인출 상태 확인 | 레일 유격·불완전 인출은 TF 기준과 실제 위치의 차이를 만들 수 있음. 인출 축 정렬 및 [`config/places.yaml`](../config/places.yaml)의 기준 인출 거리 대조. 실행 전 차단 연결은 [#15](https://github.com/Jik-Kim/ready2go/issues/15#issuecomment-5976855710) 후속 확인 사항 |

* 설치 후 서랍장 위치를 바꾸지 않음. 위치를 바꾸면 기준 포즈 재교시 + 서랍 좌표계 재측정 + 트윈 씬 수정이 필요함.
* **서랍 좌표계 등록**: TCP로 서랍 모서리 3점을 터치하여 로봇 베이스 기준 서랍 좌표계(`drawer_<id>`)를 측정하고, 실측 치수는 A에게 전달하여 트윈 씬에 반영.

### 2.3 물품 선정 기준 (Day 2 실물 파지 테스트로 확정)

- 일반 후보 선정 기준은 RG2 최대 벌림 약 110 mm 안, **높이 1.5 cm 이상 유지**, 무게 부담 없음. **지우개(11.5 mm)만 높이 기준 예외**로 확정했으며 1.0 cm로 일괄 낮추지 않음. [#8 최신 결정](https://github.com/Jik-Kim/ready2go/issues/8#issuecomment-5980582810) 참조. [문서]
- 지우개 예외의 근거는 **새 서랍 가운데 조건의 파지 3/3 성공**임([B 시험 기록](https://github.com/Jik-Kim/ready2go/issues/8#issuecomment-5977034169)). 벽 옆·전체 배치·다른 물품의 파지 검증 완료를 뜻하지 않음. 물품별 파지 힘·최종 실물 실행 검증은 [#15](https://github.com/Jik-Kim/ready2go/issues/15), 벽 옆 대응은 [#37](https://github.com/Jik-Kim/ready2go/issues/37)에서 확인함. [실측: B 보고] [문서]
- 그리퍼 손끝 개조는 하지 않음. 파지 높이는 서랍 바닥/실제 지지면을 기준으로 잡고 RG2 폭 피드백 등을 함께 확인함. 검정·광택·얇은 벽·원뿔 물품은 개별 검증함.
- 등록 물품은 장애물 포함 **10종·11개**(지우개 2개). 단일 요청은 등록 목록 전체를 대상으로 함. 아래 표의 등록은 최종 파지 승인이나 시도마다 성공한다는 뜻이 아님.
- [문서] 당근 펜은 활성 목록에서 제외했습니다. 기존 학습 클래스 11종과 class_id=5 및 과거 실측 기록은 유지하며 A의 은퇴 클래스 호환 지원은 별도입니다. 장면 프리셋·실물 미검증 구분은 [Knowledge 안내](../knowledge/README.md#p2-시작-배치-선택--e-구현c-연결-대기)를 참조하십시오.
- 파지 설정 정본은 `config/item_grasp.yaml`. 힘과 승인 조건이 미확정이면 `grip_force: null`, `grasp_verified: false`로 유지함. 다른 파트가 기본값으로 실행하지 않도록 B/C 연결이 필요함.
- 선정·시험·높이 기준 결정은 [#8](https://github.com/Jik-Kim/ready2go/issues/8), 반영 작업은 [#11](https://github.com/Jik-Kim/ready2go/issues/11)에 추적함. `docs/decisions.md`는 현재 없음.

### 2.4 장비 · 노트북 구성

| 장비 | 위치·역할 | 실행 서비스 (compose profile) | 비고 |
| :--- | :--- | :--- | :--- |
| **PC2** (서동권, RTX 4060) | 로봇 옆 · 실물 제어 | `ros2-core`(BACKEND=real), `vision`, `realsense`, `voice` (`real`) | 로봇 제어기·그리퍼와 유선 연결, 손목 RealSense USB 연결. **비전 추론은 PC2 GPU 사용**. Isaac Sim 실행도 가능하므로 B가 실물 대기 중 직접 사전 검증하거나 PC1 고장 시 트윈 예비 장비로 사용(시연 중에는 실물 제어 전용) |
| **PC1** (김병직, RTX 5060 8GB) | 트윈 · 사전 검증 · 학습 | Isaac Sim 5.1.0(네이티브) + `ros2-core`(BACKEND=sim), `dsr-emulator`, `vision` (`sim`) | YOLO 학습, 시연 중에는 실물 미러링 트윈 화면 |
| 팀원 노트북 | 개발 | `ros2-core`(BACKEND=mock), `mock-sim`, `voice` (`dev`) | GPU 불필요 |
| 네트워크 | 팀 전용 공유기 | - | 로봇 제어기 네트워크와 분리. PC1↔PC2 DDS 통신은 공유기 쪽 인터페이스로 고정 |

* 실행 로그 타임스탬프는 **Runner 한 곳에서만** 기록하여 PC 간 시계 오차 문제를 피함.
* 마이크는 시연 위치에 두고 PC2에 연결(또는 USB 마이크).
