# practice — 담당별 현재 상태

- 담당마다 `practice/<코드>/CURRENT.md` **한 장**만 유지한다: 지금 Phase, 확정 값, 막힌 점, 다음 할 일.
- 작업이 끝날 때마다 갱신하고 커밋한다. 다른 사람이 이어받을 때 이 파일만 읽으면 되도록 쓴다.
- 결론을 철회할 때는 지우지 말고 ~~취소선~~ + 이유를 남긴다.
- 날짜별 상세 기록이 필요하면 같은 폴더에 `YYYY-MM-DD_주제.md`로 둔다(선택).
- 측정값에는 [실측] / [문서] / [추정] 태그를 붙인다.
- 할 일 배정은 GitHub Issues로 한다(이 폴더는 상태 기록용).
