- **끌기 유지** — 모서리 쪽은 어차피 끌어야 함. 살포시만 닿아도 잘 끌림. (10/06 저녁 "기울여 잡기"는 안 함)

- **누르기**: 내려가다 5 N 넘으면 바로 멈춤 → 멈춘 채 3번 모두 5 N 넘으면 닿음 → 0.1 mm 씩 올려 1.5~2.5 N → 가운데 쪽으로 잡을 수 있을 만큼 (적어도 3 cm) 끌기.
- **실패하면 멈추지 않고** 탑뷰 → (인식, 지금은 시늉 — 비전 연동 때 실제) → 다시 그 위치로 끌기.
- **기울기 30° → 20°** ("30°는 너무 큼").
- 시험 흐름 (호스트, `b_flow.sh dragtest`): 홈 → 서랍 열기 → 탑뷰 → 끌기(실패면 탑뷰 → 다시) → 집기 → 트레이.
