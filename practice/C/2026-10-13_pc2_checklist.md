## 1. 10/12 남은 확인 — Unpacking (`find_with_unpack`)

> S2·S3 구성(S2 = 판 + 지우개 + 판에서 떨어진 립밤, S3 = 판 + 립밤)은 #109 배치 제안을 따른다. **실물 배치는 아직 고정·안전 확인 전**이라, 시작 전 B 가 파지·배치 안정성·손가락/아래 서랍 여유를 보고 A·E 가 사진·GT·서랍 좌표를 남긴 뒤 회차를 돈다(그 전 결과는 '배치 고정 전'으로 기록, S2/S3 수용 근거로 세지 않음).
>
> **아래 칸 배치 규칙 (A Isaac 사전 검증 10/13 + B 답 ⑧)** — 어기면 움직이기 전에 거부돼 "꺼내지 못했어요"로 끝남:
> - **판 가운데 x ≤ 120 mm, 판 긴 변을 서랍 x 방향으로** — 아래 칸 손이 닿는 깊이 129 mm 를 넘으면 판 집기 `WALL_TOO_CLOSE`(A `030225`: x 132.6 mm). 넛지는 서랍 깊이 방향으로 끌지 않아 코드로 못 풂.
> - **립밤은 판 밑·판 손가락 자리 밖** — 판 밑에 걸치면 판 집기 `NEIGHBOR_TOO_CLOSE` + 립밤은 판에 가려 치울 대상이 못 돼 서로 막힘(A `030105`). #109 배치 제안(립밤은 떨어진 곳)이면 생기지 않음.
> - **립밤은 지우개 손가락 자리 밖 (S2, A Isaac `030105` 10/13)** — 판을 치운 뒤 지우개를 집을 때 벌린 손가락 자리에 립밤이 있으면 지우개 집기 `NEIGHBOR_TOO_CLOSE` → #277 이후 넛지 없이 바로 실패, make_room 자동 연결은 P2 뒤라 **못 꺼냄**. 손가락 자리 = 지우개 가운데에서 짧은 변 방향(손가락이 닫히는 방향) ±35.5 mm × 긴 변 방향 ±20.8 mm (벌림 22+13 = 35, 손끝 바깥 13, 여유 5, 손가락 반폭 15.8 mm). 립밤(71.8 × 20 × 20 mm)은 손끝보다 높아 무시되지 않음.
>   - **배치 규칙: 립밤 가운데를 지우개 가운데에서 어느 방향이든 80 mm 이상** 떨어뜨림 — 가장 먼 경우(대각선 45°, 립밤 방향 모를 때 76 mm) + 여유. 비전 위치 오차 여유 5 mm 는 판정 안에 이미 들어 있음. A 장면은 약 30 mm 라 막힘. 아래 칸 안쪽 210 × 286 mm 라 판과 함께 둘 수 있음
>   - **전제: 지우개는 벽에서 떨어진 서랍 가운데 쪽** — 벽 가까이면 벽 판정(`WALL_TOO_CLOSE`)이 따로 걸림
>   - [B 실측 10/13: 실제 스킬 서버 집기 판정(짧은 변이 막히면 긴 변 대안까지)을 15° 간격으로] 옆·끝 나란히 최대 59 · 직각 최대 60 mm, **대각선 45° 립밤 비스듬 69 · 방향 모를 때 76 mm** (C 가 `pick_blocker` 단독으로 계산한 옆 45.5~73 · 끝 31~58.5 mm 보다 대각선이 멂 → 75 에서 80 으로)

**전날 C·E 가 정할 것**: 새 태스크 JSON 2종 — 지금 실물에서 되는 동작(서랍 열기·닫기, 서랍 안 집기·놓기(aside·`free`·pose), 트레이에 놓기, 촬영, 안내)만 조합.
- `tasks/return_items.json`(예시)은 형식 검사는 통과하지만 **트레이에서 집기**가 필요 → 지금 B 집기는 서랍 전용이라 실물 불가(#150 "아직 아님"). B 가 트레이 집기를 열지 않으면 다른 2종으로.
- **E 선정 10/13 ([#256](https://github.com/Jik-Kim/ready2go/pull/256))** — 아래 2종 (선정은 실물 성공과 별개):
  1. **"서랍 안 보여줘"** — 열기 → 탑뷰 → 촬영 → "○○, ○○가 있어요" 안내(보인 물체) → 닫기 → 홈
  2. **"○○ 옆으로 치워줘"** — 열기 → 탑뷰 → 촬영 → 집기(`scan`) → 서랍 빈 자리(`free`)에 놓기 → 닫기 → 홈

| 단계 | 할 일 | 누가 |

## 4. 음성 정지 D1 — 첫 실물 기록 ([FR-SAF-01](../../docs/requirements.md#fr-saf-01)·[AC-SAF-02](../../docs/requirements.md#ac-saf-02), #152·#187, [#260 D1](https://github.com/Jik-Kim/ready2go/issues/260#issuecomment-6135926261))

목표 5종 **B1(지우개 트레이에)** 이나 `find_item` 한 회차 중, **로봇이 저속으로 움직이는 구간**에서 마이크로 "멈춰"를 말한다. 펜던트 E-stop 을 대신하지 않는다.

| 단계 | 할 일 | 누가 |
| :--- | :--- | :--- |
| 준비 | 2인(한 명은 펜던트 E-stop 손에), 저속 확인, 정지할 구간을 B 가 정함(예: 탑뷰로 가는 `move_to_named_pose`·트레이로 옮기기). **쥔 채 구간에서 하면 물체가 손에 남음** → 처음엔 빈손 구간 권장 | B·C |
| 말하기 | 웨이크워드 + "멈춰" (E 음성 노드 경로). 마이크가 안 되면 `/voice/text_override` 로 넣되 **기록에 "글자 입력 — 음성 아님"** 으로 남김 | E 또는 C |
| 보기 | 로봇이 실제로 멈췄는지(영상·눈), B 스킬 서버 로그의 정지 확인 줄(`CANCELED` / `STOP_UNCONFIRMED`) | B |
| 막히는지 | 멈춘 뒤 새 요청 1번(예: "지우개 찾아줘") → **거절되고 로봇 동작 0** 인지 | C |
| 기록 | `run_report -n 1` 머리 "정지 시각 · 코드 · 출처 · 스텝 · 응답 +초" (`halts[]`: `requested_at`·`step_code`·`stopped_at`), E 쪽 발화 끝·STT·안내 시각, B 정지 확인 시각 → 5절 + #152 | C·E·B |
| 끝 | 사람이 그리퍼·서랍 상태 확인 → 쥔 물체·열린 서랍은 손으로 정리 → **잠금 해제 통로가 아직 없어 `docker compose restart ros2-core`**(Runner 잠금만 풀림, B 스킬 서버 기억은 남음 — 쥔 채였으면 B 복구 순서 #260 1절) → `/runner/reset_state` | B·C |

판정은 E 가 한다. 이 회차는 **요청 → 실제 정지 → 잠금 → 안내 시각을 처음 재는 것**이고, 복구·재개(FR-SAF-03·AC-SAF-04)는 계약 전이라 하지 않는다. `STOP_UNCONFIRMED` 가 나오면 그대로 기록하고 사람 확인 뒤 재시작.
